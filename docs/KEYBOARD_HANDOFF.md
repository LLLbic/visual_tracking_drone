# 本地悬停到位置式键盘控制交接

当前开发分支在已验证的纯位置起飞/悬停路径上增加手动键盘交接。实现已通过离线测试，
尚未部署、SITL/HIL或实飞验证，不能据此直接进行带桨飞行。

## 控制原则

- 起飞预发送、爬升、悬停、键盘移动、松键减速和再次定点始终由同一个线程、套接字和轨迹控制器完成。
- MAVLink 全程使用 `MAV_FRAME_LOCAL_NED` 和 `type_mask = 2552`，只让 PX4 执行位置与航向目标。
- 键盘产生的速度只用于电脑内部连续积分位置目标；报文中的 `vx/vy/vz/yaw_rate` 始终为零且被掩码忽略。
- 授权不创建发送器、不切模式、不 ARM，也不改变现有悬停目标。授权后的首包与授权前最后一个悬停包相同（时间戳和序号除外）。
- 旧版独立 `BODY_NED` 速度发送器在配置中关闭，配置校验禁止它与位置式交接同时启用。
- 不修改 PX4 参数，不发送 RC 覆盖或 `MANUAL_CONTROL`，不自动切入 Offboard。

## 人工授权条件

只有完成指定高度起飞并处于稳定悬停后，飞手才可在当前网页手动授权。授权要求：

- 实际状态为 `ARMED + IN_AIR + OFFBOARD`，实体 CH8 仍在 Offboard，CH6 急停未触发；
- 网页位于前台、已勾选现场确认、全部控制键已松开，并持续发送新鲜且顺序递增的输入报告；
- 飞控心跳、RC、姿态、本地位置和速度、落地状态及基础估计器输出新鲜有效；
- 水平位置误差不超过 0.15 m，高度误差不超过 0.15 m，水平速度不超过 0.08 m/s，垂直速度不超过 0.10 m/s；
- 稳定至少 3 秒并收到至少 15 个不同的飞控位置样本；2.5 Hz 的真实位置流允许通过，重复转发包不计新样本；
- 起飞时记录的位置源、源时间、航向及可用重置签名没有出现突变，且旧速度发送器、其他起飞流程和地面测试发送器均未运行。

当前数传中的光流 `quality=4` 已被现场确认可能是占位值。它继续显示供诊断，
但在 `flow_quality_authoritative=false` 时不参与本位置式起飞和交接授权，也不单独触发故障。
这不等于光流已验证良好；来源变化、位置/速度残差、坐标或航向突变以及估计器明确报告的故障仍会阻断或终止控制。

## 连续轨迹与边界

- `W/S` 前后，`A/D` 左右，按实时航向换算到同一 LOCAL_NED 坐标系；`Shift/Alt` 上升/下降，`Q/E` 左/右偏航。
- 水平速度上限 0.15 m/s，垂直速度上限 0.10 m/s，偏航角速度上限 8°/s；全部变化都有限加速度。
- 目标与实际水平偏差软/硬限制为 0.15/0.30 m，垂直偏差为 0.12/0.25 m，偏航偏差为 12°/25°。
- 位置目标限制在起飞点水平 0.5 m 半径内，高度限制为起飞基准上方 1–3 m。
- 松开按键或撤销授权后，内部期望速度受限减到零并保持轨迹终点；不会把已经漂移后的实际位置重捕获为新目标。
- 飞机未跟上目标时停止继续积累目标；控制循环卡顿、坐标突变或越界时不补发历史轨迹。

## 失效与飞手接管

- 网页失焦、标签页中断或输入超过 0.4 秒未更新：撤销键盘权限，原控制器减速后定点；不会自动恢复授权。
- 实体 CH8 切出 Offboard，或实际模式变为 Position/Land/RTL：停止电脑设定值，不抢回模式、不自动重启。
- 遥测/定位失效、位置帧突变、目标严重脱离或发送故障：终止本次本地控制任务，不沿用旧坐标。
- LAND、RTL 和安全处置仍使用已有统一动作路径。软件停止发送不等于飞机立即停止，最终行为仍取决于飞控现有失联策略和实体遥控链路。

## 离线验收覆盖

测试覆盖授权零副作用、交接首包连续、全流程帧和掩码不变、按键连续移动、松键减速定点、
输入超时撤权、2.5 Hz位置样本、实体模式接管、单一MAVLink序号以及旧发送器互斥。

