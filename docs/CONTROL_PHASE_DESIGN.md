# 后续 MAVSDK 跟踪控制阶段的安全边界（当前未实现）

当前版本故意没有安装、导入或调用 MAVSDK，也没有启用视觉跟踪速度控制。唯一存在的飞控上行是一个默认关闭、页面手动开启的地面测试通道：固定以 5 Hz 发送 `vx=vy=vz=0` 的 `SET_POSITION_TARGET_LOCAL_NED`，只用于建立 Offboard proof-of-life。它不会切换模式或解锁，且在已解锁、状态未知、遥测过期或本地急停时自动关闭。以下是后续真实跟踪控制阶段的接口约束，不代表当前已经启用。

## 不允许出现的行为

- 不写入或修改任何 PX4 参数。
- 不发送 `RC_CHANNELS_OVERRIDE`、`MANUAL_CONTROL` 或模拟 PWM/摇杆数据。
- 不由电脑自动解锁、起飞或切入 Offboard。
- 不因程序退出而擅自把飞行模式切到 Hold；模式选择权保留给遥控器/飞手。
- 不在 Land、Return/RTL、Position 等模式下继续发送有效速度指令。

## 将来启用速度输出前必须同时满足

1. 飞手已经通过遥控器手动选择 Offboard。
2. PX4 心跳中观测到的当前模式确实为 `OFFBOARD`。
3. MAVLink 遥测未过期，飞控 System ID 与预期设备一致。
4. 人工在电脑端完成一次独立的“允许跟踪”确认。
5. 目标框新鲜、没有超过允许的连续丢失帧数。
6. 本地急停未锁存，速度/角速度/高度边界检查全部通过。

任意条件失效时，发送层必须在一个控制周期内失效。尤其当飞手切回 Land、Return/RTL 或 Position 时，应用只观察模式变化并立即停止产生有效控制输出，不重新抢占模式。

## 推荐的后续发送接口

仅使用 MAVSDK Offboard 的机体系速度接口：`forward_m_s`、`right_m_s`、`down_m_s`、`yawspeed_deg_s`。第一版只开放 `forward_m_s` 与 `yawspeed_deg_s`，其余两项固定为零。该接口应位于独立进程，并通过一次性运行授权才能启动，默认不随系统开机自启。

紧急按钮需分层：

- 本地急停：停止本地控制意图并锁存，始终可用。
- 制动/悬停、降落、返航：只有在完成真机安全评审后才接入 PX4 Action；每项都应有二次确认、状态反馈和超时处理。
- 遥控器急停和模式开关：始终是最终人工安全手段，电脑端不得屏蔽。
